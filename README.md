# ムードトラッカー

今の気持ちを3ステップで記録する、スマホ向けのウェブアプリです（iPhone のヘルスケア「心の状態」と同じ流れ）。


1. **感情**：スライダーで「非常に不快」〜「非常に快適」を選ぶ
2. **ふさわしいもの**：その気分に合う語を選ぶ（複数可）
3. **影響するもの**：健康・家族・仕事・お金などから選ぶ（複数可）

## 記録の行き先

押した「完了」で、GitHub の API を使って、非公開のリポジトリ（`app.js` の `OWNER` / `REPO`）の `mood/` に、**1回の記録＝1つの JSON ファイル**を置きます。ファイル名は `YYYYMMDDTHHMMSS.json`（端末の現地時刻）です。

```json
{
  "at": "2026-10-05T16:31:00+09:00",
  "valence": 0.0,
  "labels": ["穏やか"],
  "influences": ["健康", "仕事"],
  "via": "mood-app"
}
```

| 項目 | 意味 |
|---|---|
| `at` | 記録した日付と時刻（端末の時刻・タイムゾーンつき） |
| `valence` | スライダーの位置。−1（非常に不快）〜+1（非常に快適）、中央が 0 |
| `labels` | ステップ2で選んだ語（複数、0 個もあり） |
| `influences` | ステップ3で選んだもの（複数、0 個もあり）。2026-10-05 の更新で、前の `influence`（1つ・文字列）から変わった |
| `via` | どのアプリから来たか |

通信できないときは、記録を端末の中にためて、あとで送り直します。

## このリポジトリは公開です

- **トークンも記録も、このリポジトリには入っていません。** コードだけです。
- 記録は、非公開のリポジトリにだけ置かれます。外のサービスには送りません（通信先は `api.github.com` だけ）。
- トークンは、設定画面で貼った端末のブラウザの中（`localStorage`）にだけ保存されます。

## 使い方

1. GitHub で、細かい権限指定のトークン（Fine-grained personal access token）を作ります。
   - Repository access：**Only select repositories** → 記録の行き先のリポジトリ1つだけ
   - Permissions：**Contents** を **Read and write**
   - Expiration：期限を付ける
2. スマホでこのページを開いて、右上の ⚙ を押し、トークンを貼って「トークンを保存」。
3. Safari の共有ボタン →「ホーム画面に追加」。
4. ホーム画面から開いたアプリで、もう一度トークンを貼ります（Safari とは保存領域が別になることがあります）。

## つくり

ビルドは要りません。`index.html`・`style.css`・`app.js`・`manifest.webmanifest`・`sw.js` だけです（ホーム画面に置くための設定と、通信できないときのキャッシュを含みます）。
円の見た目は画像ではなく、スライダーの位置からコードで描いています。

手元で試すとき：このフォルダで `npx http-server -p 8080` を実行して、`http://localhost:8080` を開きます。
